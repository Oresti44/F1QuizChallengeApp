# F1 Quiz Challenge App

A simple native Android quiz app built in Java for Mobile Programming.  
The app teaches Formula 1 knowledge through driver, team, and circuit quizzes.

## Features

- Driver quiz
- Team quiz
- Guess the circuit quiz
- Score tracking
- Local high score using SharedPreferences
- Restart quiz button
- Home button navigation
- Multi-screen Android app using Activities and Intents

## Requirements

- Android Studio
- JDK 17
- Android SDK
- Emulator or Android device

## How to Run

1. Open Android Studio.
2. Click **Open**.
3. Select the project folder.
4. Wait for Gradle sync to finish.
5. Start an emulator from **Device Manager**.
6. Click the green **Run** button.
